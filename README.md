# Matrix Data Engineering Portfolio

This is a containerized Python data application serving a dynamic frontend. 

🌍 **Live Demo:** [(https://data-engineering-portfolio-3k7f.onrender.com/)]

*🕒 **Deployment Note:** This application is deployed via Docker on Render's free tier. The server spins down after 15 minutes of inactivity to conserve compute resources. Please allow up to 50 seconds for the container to perform a cold start upon your first visit.*
